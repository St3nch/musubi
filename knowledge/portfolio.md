# VedaOps Portfolio / Authority Map

This file orients Musubi toward native VedaOps authority.

It is deliberately not a project-state mirror. Current implementation, runtime state,
project-local decisions, tickets, and deferrals must be read from each project's native
authority when they matter.

## Boundary

Registration in the VedaOps control plane does not by itself make a repository a Product
subject or institutional authority.

Reference repositories and other supporting material should be used according to their
actual role rather than promoted into this portfolio map merely because they are registered.
